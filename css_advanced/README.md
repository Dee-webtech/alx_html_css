# CSS Advanced Project

This project is part of the ALX Frontend curriculum.  
The goal is to apply **advanced CSS concepts** to style a webpage based on a Figma design.  

## 🎯 Learning Objectives
By the end of this project, I should be able to explain:
- What is CSS  
- How to add style to an element  
- What is a class  
- What is a selector  
- How to compute CSS Specificity Value  
- What are Box properties in CSS  
- How does the browser load a webpage  

## 📂 Files
- `index.html` – Base HTML structure of the page  
- `styles.css` – CSS styling for the page (created in Task 1)  

## Requirements
- No external libraries or frameworks (pure HTML/CSS/JS only).  
- Code must be **W3C compliant** and validated with W3C Validator.  
- All files end with a new line.
